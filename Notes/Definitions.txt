What does the strace and ltrace function accomplish exactly and how?

strace: trace system calls by a process. strace uses the ptrace system call to attach itself to a process

ltrace: trace library function calls by a process. ltrace uses dynamic linker instrumentation to intercept 
        library function calls, allowing it to track the flow of calls between a program and the shared libraries it uses.
